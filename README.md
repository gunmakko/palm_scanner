# Palm Scanner

iPad の画面に手のひらを置くと「スキャンされる」映画風の演出を再現する Web アプリです。
実際の生体認証は行いません。見た目と音だけの演出です。

HTML 1 ファイルで動作し、外部ライブラリは使っていません。

## デモ

GitHub Pages で公開しています。

https://gunmakko.github.io/palm_scanner/

iPad の Safari で開き、共有ボタン →「ホーム画面に追加」するとアドレスバーなしのフルスクリーンで起動します。

## 動作

| 状態 | 表示 |
| --- | --- |
| 待機 | 手の輪郭が明滅し、外周のリングが回転 |
| タッチ中 | 各接点にターゲットマーカーを表示、上から下へスキャン線が走る（約 2.6 秒）、左下に疑似ログ、スキャン音 |
| 完了 | 画面が緑にフラッシュして「認証完了」。数秒後に待機へ戻る |
| 途中で手を離す | 「中断」を表示して待機へ戻る |

PC ブラウザではマウスのドラッグでも動作します（動作確認用）。

## 使い方

1. iPad で URL を開く
2. 画面に手のひらを置く
3. スキャン線が下まで走るまでそのまま待つ

手のひらをベタ置きすると iPadOS の誤タッチ防止で接点が少なめに拾われることがあります。指先を少し立てて置くとマーカーが増えて見栄えが良くなります。演出自体は接点の数に依存しません。

## カスタマイズ

`index.html` 冒頭のスクリプト内で調整できます。

```js
const SCAN_MS = 2600;   // スキャンにかかる時間（ms）
const RESULT_MS = 2800; // 結果表示の時間（ms）
const DENY_RATE = 0.0;  // 「認証失敗」演出になる確率（0.15 で 15%）
```

色は CSS 変数で定義しています。

```css
:root {
  --bg: #04080d;
  --cyan: #3fe4ff;
  --green: #5dffb0;
  --red: #ff5f6d;
}
```

画面上の文言（「手のひらを画面に置いてください」「認証完了」など）はスクリプト内の `setStatus(...)` を書き換えてください。

## ローカルで動かす

HTML ファイルを iPad の「ファイル」アプリから直接開くとプレビュー表示になり JavaScript が動きません。
何らかの HTTP サーバで配信してください。

```sh
python3 -m http.server 8080
```

同じ Wi-Fi 上の iPad から `http://<サーバの IP>:8080/` で開けます。

## 技術メモ

- 描画: Canvas 2D
- 音: Web Audio API（オシレータのみ、音声ファイルなし）
- タッチ: `touchstart` / `touchmove` / `touchend` で全接点を追跡
- `apple-mobile-web-app-capable` を指定しているため、ホーム画面から起動するとスタンドアロン表示になる
- `touch-action: none` と `preventDefault` でスクロール・ズームを抑止
